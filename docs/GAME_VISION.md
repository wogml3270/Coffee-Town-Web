# Coffee Town Web — Game Vision

## 한 문장

모바일에서 한 손으로 캐릭터를 움직여 카페 기계를 직접 조작하고, 제한 시간 안에 주문을 완성하며 카페를 성장시키는 2.5D 타임 매니지먼트 게임이다.

## 플레이어 경험

- 화면 속 캐릭터를 직접 움직이는 손맛이 있어야 한다.
- 주문을 보고 동선을 짜고 기계를 순서대로 사용하는 판단이 핵심이다.
- 실수와 돌발 상황은 긴장감을 만들지만 즉시 회복할 방법이 있어야 한다.
- 한 판은 짧게 끝나고, 번 골드와 경험치는 다음 판의 성장으로 이어져야 한다.

## 핵심 루프

1. 카페 홈에서 캐릭터와 업그레이드를 확인한다.
2. 영업을 시작하고 들어온 주문을 확인한다.
3. 캐릭터를 움직여 재료를 집는다.
4. 기계에 재료를 놓아 레시피 순서대로 가공한다.
5. 완성 음료를 서빙하고 보상을 획득한다.
6. 제한 시간이 끝나면 결과를 저장하고 카페 홈으로 돌아간다.

## 첫 번째 Vertical Slice 범위

- 캐릭터: 1명
- 카페 맵: 1개
- 기계: 재료대, 그라인더, 에스프레소 머신, 물 디스펜서, 서빙대
- 레시피: 따뜻한 아메리카노 1개
- 주문: 동시에 1개
- 플레이 시간: 개발 검증용 60초, 제품 기본값 5분
- 입력: 모바일 가상 조이스틱과 작동 버튼, 데스크톱 키보드 대체 입력
- 저장: 게스트 로컬 저장, 로그인 사용자는 Supabase 저장

## 이번 범위에서 제외

- 멀티플레이
- 사용자 제작 콘텐츠
- 실시간 AI 에셋 생성
- 여러 층 또는 여러 카페 맵
- 복잡한 NPC 길찾기
- 결제와 광고

## 제품 원칙

- 플레이 화면의 상태 변화는 reducer/event 기반으로 처리한다.
- 게임 규칙과 렌더링을 분리해 테스트 가능한 순수 로직을 유지한다.
- 생성형 AI는 제작 도구로만 사용하고 런타임 의존성으로 만들지 않는다.
- 모바일 성능과 터치 조작을 데스크톱보다 먼저 검증한다.
